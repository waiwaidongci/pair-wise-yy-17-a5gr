# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 夜出台（繁殖季蝠群出洞计数）

「夜出台」页签登记每晚出洞计数：样点、日期、成蝠数、幼蝠数、温度、观察员、弃飞。判定全部在服务端完成，页面只展示结果。

- **只认首条**：同一样点同一晚只认首条记录，重复上报标记为「重复上报」并在首条上累加次数，不参与判定。
- **封护**：有效记录中幼蝠占比超过阈值（默认 15%，可在「洞口通行状态」面板调整）或出现弃飞，样点即封护，当晚禁止进洞。
- **复核解除**：封护后须换人（非触发记录观察员）连续两晚复核，两晚读数都低且登记时间间隔满 24 小时，自动解除。
- **人工暂停**：「人工暂停开放」后复核不会自动放开，只能「人工解除」；解除后按记录重新判定。
- **改正重判**：改正原计数、调整阈值或变更样点状态后，服务端按新值回放全部有效记录重新判定；服务启动时也会重判一次，保证派生状态与数据一致。
