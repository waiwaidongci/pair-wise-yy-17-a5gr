# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 夜出台（繁殖季蝠群出洞计数）

巡测台已补成夜出台，登记样点、日期、成蝠数、幼蝠数、温度、观察员和弃飞情况，判定全部在服务端完成并回写到记录与页面。

判定规则：

- 同一样点同晚只认首条，重复上报只把成蝠数、幼蝠数累加进首条并留痕。
- 幼蝠占比超过阈值（默认一成五，可在夜出台页面调整）或出现弃飞，样点自动封护。
- 封护后须换人连续两晚复核，两晚读数都低且间隔满二十四小时才自动解除。
- 人工暂停开放不会被自动放开，也不被自动判定覆盖。
- 原计数、阈值或样点状态经接口改正后，按新值自动重判。

看板首页直接列出"今晚不可进洞"样点；样点卡片显示封护复核进度，夜出记录卡片显示幼蝠占比与判定结果。

相关接口：

- `POST /api/emergences` 登记夜出（重复上报返回 `deduplicated: true`）
- `PATCH /api/emergences/:id` 改正计数（撞晚返回 409）
- `PATCH /api/settings/settings-emergence` 调整阈值（如 `{ "juvenileRatioThreshold": 0.2 }`）
- `POST /api/action/site-rejudge/:id` 对样点手动重判
